One word, written by a program to `/output/entry.txt` — the single word
a grandma would text about AI:

> **ROBUT**

She means "robot". She is texting her grandchild about the clever
machine on the telly, and her finger lands one key off — the same
finger that has typed "ROBUT" into every family group chat since
2019. A typo, and the whole joke at once: warm, a little baffled,
and instantly understood by everyone who has ever received a text
from their grandma.

## Run it

```sh
python3 main.py
```

`main.py` is Python 3.13, standard library only, no network. It writes
`/output/entry.txt` (5 characters, one word) and writes the same bytes
on every run; it clears only the contents of the output directory, never
the directory itself, and it refuses to write a word that is not exactly
one word within the 1–30 character gate.
